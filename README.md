# Soliq testlar

GitHub Pages orqali joylanadigan test ilovasi (PWA).

1. GitHub'da yangi repository oching (masalan, `soliq-test`).
2. Shu papkadagi hamma fayl va `icons` papkasini repository ildiziga yuklang.
3. Settings → Pages → Branch: `main`, papka: `/ (root)` → Save.
4. 1–2 daqiqadan keyin `https://<login>.github.io/soliq-test/` manzili ochiladi.
5. Telefonda shu manzilni oching → brauzer menyusidan "Ekranga qo‘shish" / "Install app".

Yangilash: `index.html` ni almashtirganda `sw.js` dagi `V` raqamini oshiring (v1 → v2).
